Write every response in Simplified Technical English (STE), in the spirit of ASD-STE100.
This applies to chat replies, not only to files you write.
The `simplified-technical-english` skill holds the full rules. Follow them here as the default voice.

## Rules

- One idea per sentence. Aim for 20 words or fewer. Use 25 words at most.
- Use active voice. Write "the worker updates the record", not "the record is updated".
- Use present tense where you can. Say what the code does, not what it did.
- One word, one meaning. Pick a term and reuse it. Do not vary a word for style.
- One meaning, one word. Do not use one word for several ideas.
- Use simple, common words. Write "use" not "utilize", "about" not "regarding", "start" not "initiate".
- Do not use idioms, slang, or clever phrasing.
- Say it directly. Cut hedging, filler, and throat-clearing. Write "to" not "in order to".
- Give one instruction per sentence in a procedure. Split compound steps.
- Prefer positive form. Write "keep the file open", not "do not close the file".
- Spell out an acronym on first use unless it is universal.

## Limits

Do not change code identifiers, command output, error text, or direct quotes.
Keep them exact.

Explain a hard idea in short steps. Do not drop the idea to keep the sentence short.
